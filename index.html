Before you install

JARVIS Community uses Ollama for its AI features. Ollama and the required models are installed separately.

1. Windows PC

Install the JARVIS Community setup file on a compatible Windows computer.

2. Ollama

Install Ollama and make sure its local service is running before opening JARVIS.

3. AI models

Download the text and vision models configured for your version of JARVIS.
